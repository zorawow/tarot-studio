# Tarot Studio｜我的塔罗书房

从第一人称窗边书房进入每日抽牌、生活日记和 Tarot Academy 的中文韦特塔罗课程。使用 React、TypeScript、Vite、Tailwind CSS 与 React Router。学习数据写入浏览器 localStorage，早晚日记和照片写入 IndexedDB。应用本身无需注册或付费 API。

## 书房 P0

- 书房是主菜单。桌面四个常显入口分别是抽牌、塔罗学院、记忆训练、每日日记。学院有微课程、牌库、提问练习三个入口，学习进度在微课程页。历史解牌与自我觉察在日记内。右上角切换窗景、声音与深浅主题。
- 室内、窗外、桌面和物件以手绘动画插画呈现，分别渲染。窗景菜单内可选择减少镜头动效。默认深色主题呈现夜晚书房，浅色模式呈现自然日光，已保存的主题偏好会继续生效。
- 方桌独立于窗景和地板。三本叠书在桌后，摊开的日记放在近处，四个功能字签贴着物件显示。左上「每日一句」按本地日期更新。
- 声音面板可选三首钢琴曲，与四种实地环境录音分别开关、按需加载。切换曲目或跟随窗景切换环境音时会淡入淡出。声音面板提供录音来源与授权。
- 工作台提供单张与四种三张牌阵。洗牌后 78 张牌在电脑上展开成紧凑的弧形，悬停或键盘聚焦可抬起单张牌，触屏可滑动选牌。独立解读之后可逐层对照位置、符号、组合和完整参考，并保存单张抽牌到晨间日记。
- 晨间写下问题、第一印象、关注点和事前想法，晚上补记事件、情绪、照片和吻合或不吻合之处。日记历史支持时间轴、日历、表格和筛选。
- 「每日日记 → 备份与恢复」导出或恢复包含课程、牌库笔记、练习、每日记录及照片的完整 JSON。「我的进度」继续处理旧版学习备份。

场景、照片和音乐的替换位置见 [书房素材说明](docs/studio-assets.md)，验证范围见 [P0 验收记录](docs/studio-p0.md)。

## 线上使用与旧记录

线上入口为 [打开塔罗书房](https://tarot-academy-study-oct29.zorawang0312.chatgpt.site/)。站点面向链接访问者开放，学习和日记数据保存在每位访问者各自的浏览器。

本机、手机、不同浏览器、端口和站点域名使用各自的存储。如果旧记录在此前的 `briskfinch64.chatgpt.site` 或本地 4173 地址，请在原环境导出 JSON，再到要长期使用的地址导入。导入采用覆盖恢复，确认前先备份两边。

## 启动

需要 Node.js 22.12+（本项目验证环境为 Node.js 24）。在这个目录打开 PowerShell：

```powershell
npm ci
npm run dev
```

浏览器访问 **http://127.0.0.1:4173/**。本机已安装依赖时，直接运行 `npm run dev` 即可。也可以双击目录中的 **启动塔罗学院.cmd**，它会检查依赖并打开浏览器。保持终端打开；按 `Ctrl+C` 停止网站。

端口固定为4173，便于每天在同一网址使用。首次尝试5173时本机拒绝监听，已改用实际验证可用的4173。若端口被另一个程序占用，先关闭旧的开发服务；确需改端口时，可以运行 `npm run dev -- --port 4180`，但浏览器会把它视作另一个存储来源。

生产构建与本地预览：

```powershell
npm run check
npm test
npm run build
npm run preview
```

运行预览前停止开发服务，两者使用同一端口。`dist/` 可部署到任何静态网站服务器。使用 HashRouter，直接访问 `/#/cards/major-0` 等子页面无需服务器配置路由回退。请通过 HTTP 服务访问，不要直接双击 `dist/index.html`。

如需同一局域网的手机访问，运行 `npm run dev -- --host 0.0.0.0`，在手机打开电脑的局域网 IP 与4173端口。不同浏览器和设备的记录分别保存，可以用导入导出迁移。

## 每天怎样使用

1. 从书房进入「塔罗学院」，选择「33 节微课程」后从推荐阶段继续学习。每节约5–10分钟，读完后用自己的语言回答练习并点击完成。
2. 到牌库看故事与符号，切换正逆位，标记学习状态，留下个人观察。
3. 用记忆卡片主动回想，或做八种知识测验。答题后会看到正确答案、解释和牌义入口。
4. 在解牌实验室先写开放问题，选择单张或三张牌阵；洗牌后逐张翻牌，先写自己的理解，再解锁参考。
5. 把练习保存到学习日记，补上心得与待核实信息。过几天回来比较原先的判断。
6. 在“我的进度”查看到期复习和薄弱牌。定期导出 JSON 备份。

首次打开为真实的零进度。每天的学习卡在当前浏览器中随机选择并固定，当地日期变化后更新，不作为运势展示。学习日期按用户浏览器的本地日历计算，避免 UTC 跨日造成连续学习误差。

## 从零开始的推荐用法

1. 在系统学习依次完成「塔罗入门概论」「原理与局限」。历史事实、解释传统和科学证据的边界会分开说明。
2. 学习「如何提出好问题」，查看至少15组改写案例，然后进入「问题优化器」。检查规则提示，选择或编辑建议，确认后带到实验室。
3. 阅读完整占卜流程，点击「跟着老师完成第一次解读」。本次使用明确标注的固定教学牌，按十步完成观察、独立解释、参考比较和记录。
4. 每天学习一张牌。用详情目录查看图像、正逆位、五种牌位、四类情境、两个完整案例和三道理解题，再做「跟着老师学解牌」。每个牌位、正逆位分别保存草稿。
5. 准备好后进入随机抽牌实验室；真实抽牌与固定教学分开。先写自己的理解，再展开参考，并保存学习日记。

问题优化器只识别有限的词语规则和场景模板；识别不可靠时会明确显示通用框架，由你补充和修改。它不会评判问题的全部语义，也不会对自由解读进行自动评分。

本次升级延续原项目和存储键 `tarot-academy:v1`，保留原牌ID、课程ID、个人笔记、历史练习和未完成草稿。旧版JSON可以导入；新增的教学练习与提问草稿一并进入备份。

手机可以用浏览器打开线上网址并添加到主屏幕。iPhone在Safari分享菜单选择「添加到主屏幕」；Android在Chrome菜单找「安装并创建快捷方式」或「添加到主屏幕」（名称依浏览器版本而异）。这是网站入口，当前没有承诺离线运行；电脑与手机记录各自保存在本机，迁移请用JSON备份。操作参考：[Apple 官方说明](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)、[Chrome 官方说明](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=zh-Hans)。

## 已实现

- **首页与导航**：书房有四个常显功能入口，子页通过「返回书房」回到主菜单。学院内可查看学习进度与牌库。
- **78张深度微课程**：每张牌独立编写故事、图像事实与象征联系、正位六个侧面、逆位五个镜头、五种牌位示例、四种生活情境。全库共157个分步案例、390个牌位示例、234道带解释的理解题。另有逐步展开的解牌练习和复盘保存。
- **问题与流程训练**：规则驱动的问题优化器、可编辑的三条建议、十步流程指南、固定教学首次解读，均可进入后续真实练习。
- **完整78张牌**：22张大阿尔卡那、四花色各14张；中英文名、RWS编号、关键词、独立故事、至少3个符号、正逆位、爱情／人际／工作／成长情境、对比牌、记忆口诀、个人笔记、收藏与学习状态。
- **八步推荐路线、33节微课程**：入门概论 → 原理与局限 → 正确提问 → 完整占卜流程 → 78张牌 → 基础牌阵与运用 → 初级模拟 → 综合复习。保留原27节课的ID和记录，新增入门学院与首次教学解读。所有课程自由进入。
- **八种知识训练**：看牌猜名、看牌识义、关键词配对、正逆位判断、易混淆比较、情境应用、图像观察、牌义推理；另有翻卡回想与熟悉程度自评。每组最多10张不同的牌。
- **简化间隔复习**：首次正确1天，接着3天，再约1.8倍延长，最长60天；错误回到1天。自评还不熟／有印象／记住了也可调整下次日期。薄弱牌为曾答题且正确率低于70%，或累计答错至少2次的牌。
- **解牌工作台**：单张和四种三张牌阵，使用浏览器随机数与 Fisher–Yates 洗牌。同次抽牌无重复实体牌。牌扇中的牌可点按、触屏滑动或用键盘选择。翻牌并独立写至少10个字后可查看完整参考。草稿刷新后可恢复。
- **完整日记**：记录日期、问题、牌与方向、独立解读、当时参考、心得和标签；新增随记、编辑、删除确认；按关键词、牌名和日期范围查询。
- **学习统计**：已学习牌数、四种熟悉状态、分类完成度、课程完成、真实答题正确率、7／30天记录次数、到期复习和薄弱牌入口。
- **深色／浅色主题**：默认夜晚书房，使用暖灯、深木和柔和金色。浅色使用奶油白、鼠尾草绿和自然窗光。React 启动前读取偏好，减少主题闪烁。
- **本地数据保护**：格式版本、完整备份导入校验、覆盖确认、读取损坏时保留原始数据、存储失败提示、多标签页同步。

### 扩展为七阶段课程

`Stage.id → Lesson.stageId → Lesson.id → sections` 是第一版的课程层级。进度以稳定课节ID保存，不以标题、数组索引或“第几阶段”存储。页面从数据渲染课程数量和顺序，因此增加阶段或重新排序无需改写页面或清除进度。

新增牌义联系、进阶牌阵、综合解牌、案例实战或个人体系课程时：

1. 在 `courses.ts` 增加或调整 `stages`，保留现有阶段和课节ID；用 `order` 标记顺序。
2. 添加对应 `Lesson`，填入 `stageId`、内容段落、关联牌ID、练习与参考；新增内容自动进入学习路径和进度统计。
3. 若未来需在阶段之下再增加单元，可给课节添加可选 `unitId` 并在课程列表分组；既有 `LessonProgress` 仍按同一个课节ID读取。

### 练习与未来牌阵

`PracticeRecord` 独立保存 `id`、`kind`、日期、`spreadId`、问题、牌及位置、正逆位、原始解读、当时的参考文本、复盘、标签和可选 `lessonId`。参考以当时文本快照保存，后续修改课程牌义不会改写旧记录。

新增牌阵可在 `learning.ts` 的 `spreads` 添加稳定ID与位置。当前界面专为1／3张布局优化；扩展大牌阵时添加相应布局即可复用抽牌和记录结构。新增练习类型时扩展 `PracticeKind` 及导入校验，不需迁移已有阅读和随记。

### 数据升级与账户同步

存储键为 `tarot-academy:v1`，数据带有 `schemaVersion: 1`。`migrateState()` 是唯一的读取、导入与未来迁移入口，校验日期、状态、数量、牌ID、记录重复与草稿结构。现有备份缺少新加的可选草稿字段时会补为 `null`；未知但合法的课节ID会保留。

破坏性结构变更应提高 `schemaVersion`，在这个入口逐版本迁移，而非更换存储键并丢掉旧资料。未来接数据库或账户同步时，替换 `store.tsx` 的读写机制，保留领域ID、纯逻辑与页面动作。记录已有独立ID和更新时间，可在真正引入同步时制定冲突策略；第一版不引入空的后端或账户框架。

## 重要的保存说明

- localStorage 属于**当前设备、当前浏览器、当前网址（含端口）**。`localhost` 与 `127.0.0.1`、本地地址与线上地址各自保存；请固定使用同一个地址。
- 刷新或正常关闭再打开会保留数据。清空网站存储、无痕窗口关闭、浏览器空间不足可能影响保存。页面会显示可检测的错误。
- 在「每日日记 → 备份与恢复」导出完整 JSON，可迁移到其他浏览器或设备。导入采用覆盖恢复，确认前可以先导出当前数据。仅迁移旧版学习进度时可使用「我的进度」。
- 若浏览器限制下载，可用“复制备份文本”打开完整 JSON，复制或全选后粘贴到文本编辑器，保存为 UTF-8 `.json` 文件。
- 主题偏好独立保存，备份会记录其值供查看；导入学习数据不会改动当前主题。
- 多标签页采用浏览器存储事件同步，最后一次写入生效。第一版适合个人单设备日常使用；建议避免在两个标签页同时编辑同一条记录。

## 素材与教学依据

站内使用 Pamela Colman Smith 绘制的原始1909年 Rider–Waite–Smith Pam-A 牌面扫描，所有图片保存在 `public/cards/`，加载网站时不向外部图片服务请求。

- [镜像提供者的逐牌组来源与公版声明](https://github.com/mixvlad/TarotCards/blob/840b84d012c6b74dc1634fa2d00d1b21f5b28093/SOURCES.md)：原版扫描由 Steve P. 整理修复，明确标注 Public Domain。
- [扫描原始出处](https://steve-p.org/cards/RWSa.html)。
- [Wikimedia Commons 原版与现代重新配色版的区别](https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck)。
- [A. E. Waite《The Pictorial Key to the Tarot》公版原文](https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot)。
- `public/cards/sources.json` 包含固定来源提交、每张图的URL、文件大小与SHA-256，便于审计和替换。图片失效会回退到完整学习卡，无破图。

所有中文课程、记忆提示与情境应用为本项目自编教学文本，采用常见现代 RWS 学习框架，并不声称唯一解释或逐字再现 Waite 的历史占断。原书的神秘学信念属于历史语境，课程将其与可观察事实区分。塔罗不作为经科学验证的确定性未来预测；健康、法律、财务等问题依赖事实与专业服务。

## 验证

`npm test` 使用 Node assert 检查78张牌、课程结构、题型、抽牌去重、学习排期、备份校验、书房设置和日记模型。

浏览器验收需要先启动开发服务，再在另一个终端运行：

```powershell
npm run test:browser
```

脚本优先使用本机 Chrome 或 Edge，不会打开已有的个人浏览器资料。其他系统可安装 Playwright Chromium，或以 `TAROT_CHROME_PATH` 指定浏览器。`TAROT_TEST_URL` 可指定要验收的网站地址。脚本验证真实点击、刷新后状态、课程完成、八种题型、卡片自评、三张抽牌、先解读后参考、日记CRUD、JSON导入导出，以及390px手机布局。截图和通过记录输出至 `docs/`。

本版同时保留了本地可运行项目与构建产物，不要求启用在线托管。未来更复杂的牌义联系课程、进阶牌阵、案例评分及个人解牌体系可以沿以上稳定ID与记录结构继续添加。

书房和学院的浏览器验收分别记录在 `docs/studio-verification.json` 与 `docs/browser-verification.json`。在开发服务器运行时，可设置 `STUDIO_BROWSER_URL=http://127.0.0.1:4173` 后执行 `node --experimental-strip-types tests/daily.test.ts`，覆盖原生 IndexedDB、早晚记录、照片、历史筛选、导出和恢复。
